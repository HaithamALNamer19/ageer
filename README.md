# منصة إدارة المستندات وتوليد روابط ورموز QR مخصصة لكل شخص

نظام ويب متكامل يتيح لك رفع الصور والمستندات (بشكل فردي أو دفعات متعددة)، وتوليد رابط فريد وكود QR مخصص لكل شخص لمشاركته مباشرة.

---

## المميزات الرئيسية
1. **رفع دفعات متعددة من الصور:** إمكانية رفع عشرات الصور دفعة واحدة مع تحديد اسم الشخص لكل صورة.
2. **رابط فريد وكود QR مخصص:** لكل صورة رابط خاص بها (`/v/xxxxxx`) وكود QR جاهز للتحميل بدقة عالية (PNG).
3. **صفحة استعراض متجاوبة وأنيقة:** مصممة للهواتف وأجهزة الكمبيوتر مع ميزة العرض بملء الشاشة، التحميل، والطباعة.
4. **دعم الشبكة المحلية والدومين الخاص:** 
   - يعمل مباشرة داخل شبكة الـ Wi-Fi المحلية بحيث يمكن مسح الكود من الهاتف فوراً.
   - يدعم تعيين دومين مخصص (مثل `https://your-domain.com`) وتحديث جميع الأكواد بنقرة واحدة.

---

## كيفية التشغيل السريع
1. افتح المجلد: `qr-doc-viewer`.
2. اضغط نقرتين على ملف `start.bat` أو شغل الأمر:
   ```bash
   node server.js
   ```
3. افتح المتصفح على الرابط:
   - لوحة التحكم: [http://localhost:3000](http://localhost:3000)
   - من الهاتف عبر نفس شبكة الواي فاي: `http://10.179.248.187:3000`

---

## نشر الموقع على الإنترنت (ليعمل في أي مكان في العالم)
لكي يستطيع أي شخص في العالم مسح الكود دون أن يكون معك على نفس شبكة الواي فاي، يمكنك نشر الموقع بسهولة عبر:
- **خدمات الاستضافة المجانية:** مثل [Render.com](https://render.com) أو [Railway.app](https://railway.app).
- **أو استخدام نفق مجاني فوري (Cloudflare Tunnel أو Ngrok):**
  ```bash
  npx localtunnel --port 3000
  ```
  ثم وضع الرابط الناتج في نافذة «إعدادات الدومين» داخل لوحة التحكم.
